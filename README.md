# CareerFlow

A focused job application tracking and pipeline management platform engineered for final-year students and recent graduates (0–2 years experience).

---

## 📌 Project Overview
- **Project Type:** Product Management Portfolio Project (Full-Stack MVP)
- **Primary Objective:** Deliver a clutter-free, actionable tracking platform helping early-career applicants track job applications, assessment/interview milestones, and follow-ups.
- **Tech Stack (Planned for Phase 7):** Next.js (TypeScript, React), Tailwind CSS, shadcn/ui, Supabase (PostgreSQL + Auth + RLS), Zod, Recharts, deployed via Vercel.
